# Orbitly 0.26.32

**App update only.** The server needs no change.

## Fixed
- **"This phone's encryption key can't be read (Reason: device-id-format)" on the Encryption keys screen.** The key was stored, but the small note of this phone's id next to it had been damaged. The app now writes that note again by itself, but only after your server confirms that this phone's key is yours. The key itself is never changed or deleted. You do not need to set the phone up again, and you do not need to restore anything.
- **Encryption keys has a Repair button for this problem, and Try again repairs too.** If your server has no record of the key, the screen says so in plain words and the way out is **Set this phone up again**.
- **Diagnostics now says this is repairable** instead of just "not usable".

## If your phone shows the key message
Do not tap "Set this phone up again" first. Update, open Encryption keys and tap Try again (or Repair). If it stays, send the Diagnostics report from **Settings > Advanced**.

## Not tried on a real device yet
This was checked on a computer against a pretend key store and a pretend server only. We do not know how the note got damaged. If the message is still there after updating, the Diagnostics report will say why.
