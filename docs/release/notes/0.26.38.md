# Orbitly 0.26.38

Security hardening, a sturdier background sync, and a clearer admin map.

## For everyone
- **Private circles stay private.** A Private circle can no longer be switched back to normal mode. If you need a normal circle, make a new one.
- **Repair encryption.** If a Private circle says its key is not approved, there is now a Repair encryption action that re-publishes your phone's key and asks for approval again.
- **Better background updates.** Old held points are no longer sent in a stale burst, and a phone that dozes now takes a fresh position on its heartbeat.
- **Battery reminder.** On Android a red banner stays on the map until Orbitly is set to Unrestricted battery. Samsung steps are spelled out.
- **Map pins.** Pins that sit close together fan out more clearly, and the solo bottom sheet covers less of the map.
- **New members** only see a circle's history from the day they joined.
- Invite codes lock out after repeated wrong tries.

## For admins
- The admin map shows a banner if map tiles are blocked and falls back to a plain map. Places shows a Retry if it cannot load.
- Dawarich export needs the admin location setting, is logged, and never includes Private circles.
- Password reset and email change now sign the person out everywhere and revoke their share links.
- App downloads are checked against the release checksums.
- Backups made by the scripts are now authenticated (old backups still restore).
- ntfy needs random topics and can use a token. If you set PLATFORM_ADMIN_EMAIL for an existing account, PLATFORM_ADMIN_PASSWORD must now match it too. See the docs.
