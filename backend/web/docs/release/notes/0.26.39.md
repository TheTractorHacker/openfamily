# Orbitly 0.26.39

A small follow-up that keeps invite joins working during guessing floods and updates the server runtime.

- Invite codes: a flood of wrong guesses from many addresses can no longer stop everyone from joining. Guessing is still blocked per code, per person and per address; during a flood, tries are just slowed down.
- Server updated to Go 1.27.4, which fixes a web-server security issue.
