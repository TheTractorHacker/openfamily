# Orbitly 0.26.35

Android app and server update: circles you join by code now show up and stay selected, and people can join a circle from a web page.

## Circles (the app)

### Fixed
- **A phone in only one circle no longer says "No family" or "You are not in a circle yet".** If that one circle was made in the app or joined with a code, the phone now selects it by default.
- **Orbitly remembers the circle you picked last.** Close the app, open it again, or update it: the same circle comes back. A short or old circle list no longer makes the app forget your pick.
- **The circle drop-down on the map refreshes each time you open it**, so a circle you were just added to appears.
- **Turning on Private mode** now says in plain words when this phone's key is not approved in the circle yet, and what to do (Settings > Encryption keys, pick the circle, approve this phone), instead of "the new key must be wrapped to the caller's own device".

## Joining by code (the server, needs the new server image)

### New
- **A web join page.** Open your server's /join page, type the code, then your name, email and a password you choose. The account is created and put in that circle. Then install the app and sign in.
- **Sign-up in the app accepts codes for circles made in the app**, not only old family codes.
- **Admin: add an existing account to a circle.** On the Circles page, pick the person and a role, then Add.

## Not tried on a real device yet
All of this was checked on a computer only. We do not yet know why one phone's key is not approved in a circle; the message now explains it, but Private mode on that circle still needs the key approved first. Slowness on the map and the layout of overlapping pins were not changed.
