# Orbitly 0.26.37

Android app and server update: less battery use while walking or standing still, and a round of security fixes.

## Battery (the app)

### Changed
- **Walking and standing still now use less battery.** While you walk and nobody is watching, Orbitly keeps your points on the phone and sends them together about every 45 seconds, instead of one at a time. While you stand still it sends about once every 4 minutes. Nothing changes when you drive, when someone has the map open, when someone asks where you are, or when the app is open: positions still go out straight away.
- **The "Syncing…" chip no longer flashes** during normal sending. It only appears if updates are still waiting after 45 seconds, which means something is stuck.

## Circles (the app)
- **Private circles no longer fail open.** If Orbitly cannot work out how to send a position for a Private circle, it holds the position back instead of sending it in the clear. People with no Private circle are not affected.
- **Changing the server address while signed in now signs you out first**, so your login is never sent to the new address.
- **Release builds no longer write every location fix to the phone's log.**

## Security (the server, needs the new server image)
- An admin can no longer add an account to a Private circle from the admin page, and with admin location access off an admin cannot add their own account to a circle.
- Trips respect "sharing paused" and "sharing off".
- An old invite code can no longer bring a deleted circle back.
- Live connections now close when the login expires or the session is signed out, and each person is limited to 8 at a time.
- Share links stop working after a password change, a password reset, or "sign out everywhere".
- The admin web page's **Sign out** now ends the session on the server.
- Profile pictures are size-checked before they are opened and are saved without location data.
- Invite codes are no longer written in full to the audit log. Several input fields now have length limits.

## Not tried on a real device yet
The battery change was checked on a computer only. Please walk with the phone in your pocket and look at the family map on another phone: it should still move within seconds when the map is open. Some security findings need a decision and are not changed here (for example what a server can do to a Private circle, SOS from Private circles, and how far back a new member can see).
