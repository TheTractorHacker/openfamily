# Orbitly 0.26.41

A self-heal for phones the server has forgotten, found by the new Self-test.

- If the server no longer has your phone registered (for example it was removed from your devices list), uploads used to fail quietly with "device not found" until you signed out and back in. Orbitly now registers the phone again by itself, in the map, in the Self-test and in the diagnostics report, and sends the position that failed.
