# Orbitly 0.26.31

**App update only.** The server needs no change.

## Fixed
- **Private circle positions stuck "waiting" while the app is closed, because the phone had lost the note of which account its key belongs to.** The part of the app that sends your position in the background reads that note, so with it missing every run stopped and positions stayed on the phone. The app now writes the note back by itself once your server confirms the key is yours. The key itself is never changed or deleted. You do not need to set the phone up again.
- **The Encryption keys screen no longer tells you to open Encryption keys while you are on it.** It now says what is wrong in plain words and has a **Repair** button, and **Try again** repairs too.
- **Diagnostics and the startup check can no longer say "fine" while the app refuses the key.** If something still fails, the report now names what (for example "flush_unreadable:empty-user-id"), so we can fix it.

## What may not be fixed
The "This phone's encryption key can't be read" message on the Encryption keys screen of the phone that showed it is **not explained** by the missing note, and we could not reproduce it. It may still be there after updating. If it is, the Diagnostics report now names the cause.

## If your phone shows the key message
Do not tap "Set this phone up again" first. Update, open Encryption keys, tap Try again (or Repair if it is offered). If it stays, send the Diagnostics report from **Settings > Advanced**.

## Not tried on a real device yet
This was checked on a computer against a pretend key store and a pretend server only. We have not seen it on the phone that had the problem, and we do not know for certain why that phone lost the note. If the message is still there after updating, the Diagnostics report will say why.
