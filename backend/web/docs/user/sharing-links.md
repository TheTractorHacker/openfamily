# Sharing links

Want a friend or a babysitter to follow you for an evening, without installing
anything? Create a **share link**.

1. In the app open Sharing and choose **Share a link**.
2. Pick how long (from a minute up to three days) and add a label.
3. Send the link. Anyone who opens it sees your live position on a small web
   page: your name, a dot on the map and battery. No history, no account.

Stop it at any time from the same screen; the link stops working at once.
Links expire on their own. Treat a link like a house key you lent out: anyone
who has it can follow you until it ends. Server admins can list and revoke all
links on the admin web **Sharing** page. Technical details: [Share links](../share-links.md).
